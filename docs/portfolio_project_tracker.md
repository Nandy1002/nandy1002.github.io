## 5. Risk Tracker

- Large WebGL builds → slow loading
- Too many projects → cluttered UI
- Weak visuals → low recruiter interest
- Overcomplicated JS → harder maintenance

Mitigation:
- Keep it simple and fast
- Focus on best projects only
