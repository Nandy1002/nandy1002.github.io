## 🖥️ About This Portfolio
This portfolio itself is a custom-built, premium web application designed to showcase technical skills and creative projects.

- **Frontend**: Pure HTML5, Vanilla JavaScript, and Tailwind-inspired custom CSS.
- **Visuals**: Modern "Bento Box" layout, neon-cyan aesthetics, glassmorphism, and dynamic animations.
- **Dynamic Content**: Project data and skills are handled via JSON files for easy updates.
- **Hosting**: Deployed automatically via **GitHub Actions** to GitHub Pages.

### Local Development
To view the site locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/Nandy1002/nandy1002.github.io.git
   ```
2. Open `index.html` in any modern web browser or use a local server like Live Server (VS Code extension).
