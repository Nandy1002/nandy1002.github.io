# FPS Inventory System - Assets Folder

Place project media files here:

## Expected Files
- `thumbnail.jpg` or `thumbnail.png` - Project card thumbnail image (recommended: 800x600px)
- `hero.jpg` or `hero.png` - Full width hero image for detail page (recommended: 1920x1080px)
- `demo.mp4` - Gameplay demo video (optional, will be played inline on project detail page)
- Additional screenshots: `screenshot-1.jpg`, `screenshot-2.jpg`, etc.

## JSON Reference
Update `data/projects.json` with paths like:
```json
"thumbnail": "assets/projects/fps-inventory-system/thumbnail.jpg",
"heroImage": "assets/projects/fps-inventory-system/hero.jpg",
"demoVideo": "assets/projects/fps-inventory-system/demo.mp4"
```
